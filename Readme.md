# PolyVinyl 支持

感谢您使用 PolyVinyl！

我们致力于提供最沉浸的黑胶音乐体验。如果您在使用过程中遇到任何问题，或者有功能建议，请随时联系我们。

### 联系方式
📧 **电子邮件**: feedback.polyvinyl@hotmail.com

### 常见问题 (FAQ)

**Q: 支持 Spotify 吗？**
A: 目前我们仅支持 Apple Music 和本地文件（MP3, FLAC 等）。

**Q: 如何导入本地音乐？**
A: 前往“资料库”页面，点击“+”号图标即可从“文件”App 中导入音频文件。

**Q: 为什么封面不显示？**
A: 请检查您的网络连接，或确保歌曲在资料库中匹配正确。对于本地文件，请尝试重新导入。

**Q: 为什么自动匹配的信息/封面不对？**
A: 我们的智能匹配引擎依赖文件名。建议您完善音频文件的命名，包含“歌手名 - 歌名 - 专辑名”，以提高匹配准确率。

**Q: 为什么上传的歌词不显示？**
A: 请确保歌词文件（.lrc）与音频文件拥有完全一致的文件名，并且位于同一个文件夹内。

### Contact Us

### FAQ

**Q: Does it support Spotify?**
A: Currently we only support Apple Music and Local Files (MP3, FLAC, etc.).

**Q: How to import local music?**
A: Go to the Library tab and tap the "+" icon to import audio files from your Files app.

**Q: Why is the album cover not showing?**
A: Please check your network connection or ensure the song is matched correctly in your library. For local files, try re-importing them.

**Q: Why is the metadata matching incorrect?**
A: Our matching engine relies on file names. Please rename your audio files to include details like `Artist - Song - Album.mp3` to improve accuracy.

**Q: Why are my uploaded lyrics not showing?**
A: Please ensure the lyric file (.lrc) has the exact same filename as the audio file and is in the same folder.

A: 現在、Apple Music とローカルファイル（MP3、FLAC など）のみ対応しています。

**Q: ローカル音楽をインポートするには？**

**Q: アルバムアートが表示されないのはなぜですか？**

A: マッチングエンジンはファイル名に依存します。マッチングの精度を高めるために、「アーティスト名 - 曲名 - アルバム名.mp3」のようにファイル名を変更することをお勧めします。

**Q: アップロードした歌詞が表示されないのはなぜですか？**
A: 歌詞ファイル（.lrc）がオーディオファイルと全く同じ名前であり、同じフォルダ内にあることを確認してください。

**Q: 로컬 음악을 어떻게 가져오나요?**
A: '보관함' 탭으로 이동하여 '+' 아이콘을 누르면 '파일' 앱에서 오디오 파일을 가져올 수 있습니다.

**Q: 자동 매칭된 정보나 커버가 틀린 이유는 무엇인가요?**
A: 저희 매칭 엔진은 파일명에 의존합니다. 매칭 정확도를 높이려면 오디오 파일 이름을 '아티스트명 - 곡명 - 앨범명.mp3'와 같이 수정해 보시기 바랍니다.

**Q: 업로드한 가사가 표시되지 않는 이유는 무엇인가요?**
A: 가사 파일(.lrc)이 오디오 파일과 이름이 정확히 일치하고 같은 폴더에 있는지 확인해 주세요.
